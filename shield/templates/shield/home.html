Threat Categories

Social Shield can identify different types of harmful content.

S

Safe

Normal messages that do not show suspicious behavior.

SP

Spam

Unwanted promotional or repeated messages.

P

Phishing

Messages attempting to obtain passwords, OTPs or sensitive information.

?

Suspicious

Messages containing potentially suspicious behavior or links.

A

Abusive

Messages containing insulting or abusive language.

About Social Shield

Social Shield is a Machine Learning and Natural Language Processing based threat detection system.

Machine Learning

A trained Machine Learning model analyzes the text and predicts the type of threat.

Natural Language Processing

NLP techniques help the system process and understand textual messages.

Threat Detection

The system classifies messages as Safe, Spam, Phishing, Suspicious or Abusive.
